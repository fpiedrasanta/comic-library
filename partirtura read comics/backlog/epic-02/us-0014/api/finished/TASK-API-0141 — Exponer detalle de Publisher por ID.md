# TASK-API-0141 — Exponer detalle de Publisher por ID

## Objetivo

Exponer un endpoint para obtener la información detallada de una editorial por su identificador, requerido por el Dashboard para edición sin depender de `location.state` ni datos mock.

## Endpoint solicitado

```
GET /api/admin-publishers/{publisherId}
```

## Contrato esperado

Request parameters:
- publisherId: long (publisher identifier)

Response 200:
{
    "success": true,
    "message": "Publisher detail retrieved successfully.",
    "code": 200,
    "payload": {
        "id": 1,
        "name": "Marvel Comics",
        "description": "American publisher of comic books.",
        "website": "https://www.marvel.com",
        "countryId": 1,
        "countryName": "United States",
        "foundedYear": 1939,
        "history": "History text...",
        "isAlive": true,
        "imageId": 123,
        "color": "#ED1C24",
        "isFeatured": true,
        "isActive": true,
        "createdAt": "2026-01-01T00:00:00Z"
    }
}

Response Type: ApiResponse<AdminPublisherDetailDto>

Errores:
- 401 Unauthorized
- 403 Forbidden
- 404 Not Found ("La editorial no existe.")

## Reglas

- Requiere autenticación y rol Administrator.
- No debe exponer datos sensibles.
- La operación es read-only.
- Debe mantenerse la misma estructura utilizada por los controllers administrativos existentes.
- No debe introducir lógica de negocio en el controller; delegar en el servicio.
