# TASK-API-0143 — Exponer endpoint de subida de imagen para Publisher

## Objetivo

Exponer un endpoint para subir/crear una imagen asociada a una editorial, requerido por el Dashboard para completar el flujo de creación y edición con imagen.

## Endpoint solicitado

```
POST /api/admin-publishers/{publisherId}/image
```

Nota del humano: No sería conveniente tener un ImageController, con POST, PUT, DELETE y GET (este ya está)? y reutilizarlo para el Alta/Baja/Modificación del avatar del usuario?

## Contrato esperado

Request:
- Content-Type: multipart/form-data
- Body:
  - image: IFormFile (binary image file)

Response 200:
{
    "success": true,
    "message": "Publisher image uploaded successfully.",
    "code": 200,
    "payload": {
        "imageId": 123,
        "urlImage": `/images/{id}`
    }
}

Response Type: ApiResponse<object>

Errores:
- 400 Bad Request ("El archivo de imagen es obligatorio.")
- 404 Not Found ("La editorial no existe.")
- 415 Unsupported Media Type (si el formato no está permitido)
- 500 Internal Server Error

## Reglas

- Requiere autenticación y rol Administrator.
- Debe reutilizar la entidad y estrategia de almacenamiento existente de `Image`.
- Debe validar que el archivo sea una imagen (formatos compatibles: jpg, jpeg, png, webp, gif).
- Debe convertir la imagen a WebP y almacenarla con nombre GUID, siguiendo el patrón existente.
- Debe validar que la editorial existe antes de asociar la imagen.
- No debe exponer rutas internas de almacenamiento.
- La imagen creada debe quedar con `IsActive = true` para que pueda referenciarse desde `Publisher.ImageId`.
