# TASK-API-0142 — Ampliar listado administrativo de Publisher con campos de detalle

## Objetivo

Ampliar el DTO de listado de editoriales para que la grilla del Dashboard pueda mostrar color, imagen y estado de existencia sin requerir llamadas adicionales por fila.

## Endpoint afectado

```
GET /api/admin-publishers
```

## Cambio solicitado

Ampliar `AdminPublisherListItemDto` para incluir:
- `color: string` (hexadecimal, ej: `#ED1C24`)
- `urlImage: number` (`/images/{id}`)
- `isAlive: boolean`

El contrato de respuesta del listado debe quedar alineado con la información que el Dashboard requiere visualizar en la grilla:
- Imagen cuando exista.
- Nombre.
- País.
- Color mediante muestra circular.
- `IsFeatured` mediante check verde/cruz roja.
- `IsAlive` mediante check verde/cruz roja.
- `IsActive` mediante check verde/cruz roja.
- Acciones correspondientes a su estado.

## Reglas

- Mantener la paginación, búsqueda y ordenamiento existentes.
- No modificar la estructura general de `ListResponse`.
- No introducir lógica de negocio en el controller.
- Actualizar `project/endpoints.md` para reflejar el DTO ampliado.
