# US-0022 — Administrar tipos de lista

## Objetivo

Permitir al administrador gestionar los tipos de lista disponibles en el sistema.

Los tipos de lista clasifican las listas de obras y podrán ser utilizados tanto por **System Lists** como, en el futuro, por **User Lists**.

Ejemplos:

* Arco argumental
* Saga
* Evento
* Orden de lectura
* Recomendación

## Actor

Administrador autenticado.

## Funcionalidad

El administrador podrá:

* Listar tipos de lista.
* Buscar por nombre.
* Filtrar por estado activo/inactivo.
* Ordenar por nombre.
* Paginar resultados.
* Crear un tipo de lista.
* Editar el nombre de un tipo de lista.
* Desactivar un tipo de lista.
* Reactivar un tipo de lista.

## Modelo

`ListType`:

* `Id`
* `Name`
* `IsActive`
* `CreatedAt`

## Reglas

* `Name` es obligatorio.
* `Name` debe ser único.
* `Id` es inmutable.
* La eliminación es lógica mediante `IsActive`.
* No existe eliminación física.
* Desactivar un `ListType` no elimina ni modifica las listas que ya lo utilizan.
* Un `ListType` inactivo no debe poder seleccionarse para crear nuevas listas.
* Los tipos de lista pueden ser utilizados por System Lists y, posteriormente, por User Lists.
* El origen de una lista (`System` / `User`) no forma parte de `ListType`.

## Fuera de alcance

* Administración de listas de obras.
* Administración de obras dentro de listas.
* Creación de User Lists.
* Privacidad o visibilidad de listas.
* Compartir listas.
* Eliminación física.
* Jerarquías o subtipos de listas.
* Sinónimos o aliases de tipos.

## Criterios de aceptación

* El administrador puede crear, editar, listar, buscar, filtrar, ordenar, paginar, desactivar y reactivar tipos de lista.
* No se permiten nombres vacíos.
* No se permiten nombres duplicados.
* La desactivación es lógica.
* Las relaciones existentes con listas se preservan al desactivar un tipo.
* Los tipos inactivos no pueden seleccionarse para nuevas listas.
* Las operaciones requieren autenticación y rol `Administrator`.
* Se respetan los contratos y convenciones existentes del Backend y Dashboard.
