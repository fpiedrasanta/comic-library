# US-0021 — Administrar etiquetas

## Objetivo

Permitir a los administradores gestionar las etiquetas utilizadas para clasificar obras.

## Actor

Administrador autenticado.

## Datos

Una Etiqueta contiene:

* `Id`
* `Name`
* `IsActive`
* `CreatedAt`

## Funcionalidad

El administrador puede:

* Listar etiquetas.
* Buscar por nombre.
* Filtrar por estado.
* Ordenar.
* Paginar.
* Crear una etiqueta.
* Modificar el nombre.
* Desactivar una etiqueta.
* Reactivar una etiqueta.

## Reglas

* `Name` es obligatorio.
* `Name` debe ser único.
* `Id` es inmutable.
* La desactivación es lógica mediante `IsActive`.
* No existe eliminación física.
* Desactivar una etiqueta no debe eliminar ni modificar las relaciones existentes con las obras.
* Una etiqueta inactiva debe poder distinguirse de una activa en la administración.
* No agregar atributos fuera del alcance de esta US.

## Fuera de alcance

* Administración de relaciones Etiqueta/Obra.
* Eliminación física.
* Perfil público de etiquetas.
* Búsqueda pública de etiquetas.
* Estadísticas por etiqueta.
* Jerarquías o etiquetas anidadas.
* Sinónimos o alias.

## Criterios de aceptación

* Se pueden listar etiquetas con paginación.
* Se puede buscar por nombre.
* Se puede filtrar por `IsActive`.
* Se puede ordenar.
* Se pueden crear etiquetas.
* No se permiten nombres duplicados.
* Se puede modificar el nombre.
* Se pueden desactivar y reactivar etiquetas.
* `Id` no puede modificarse.
* Las relaciones existentes con obras se conservan al desactivar una etiqueta.
* Solo usuarios con rol `Administrator` pueden administrarlas.
* La implementación reutiliza las convenciones existentes del proyecto.
