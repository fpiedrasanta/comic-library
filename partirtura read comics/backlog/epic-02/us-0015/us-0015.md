# US-0015 — Administrar franquicias

## Objetivo

Permitir que el administrador consulte, cree, modifique, active y desactive franquicias del catálogo, asociándolas obligatoriamente a una editorial.

Una franquicia representa una agrupación editorial o conceptual que puede contener múltiples series y, posteriormente, novelas gráficas relacionadas.

La administración de franquicias forma parte del catálogo administrado exclusivamente por el administrador de la plataforma.

---

## Alcance funcional

El administrador podrá:

* Consultar el listado de franquicias.
* Buscar franquicias.
* Filtrar franquicias.
* Ordenar franquicias.
* Crear una nueva franquicia.
* Editar una franquicia existente.
* Cambiar la editorial asociada a una franquicia.
* Desactivar una franquicia.
* Reactivar una franquicia.
* Definir una imagen representativa.
* Definir un color identificatorio.
* Marcar una franquicia como destacada.
* Indicar si una franquicia continúa vigente.

---

## Datos de una franquicia

Una franquicia tendrá como mínimo los siguientes datos:

| Campo       | Descripción                                          | Obligatorio |
| ----------- | ---------------------------------------------------- | ----------- |
| Name        | Nombre de la franquicia                              | Sí          |
| Description | Descripción de la franquicia                         | No          |
| Publisher   | Editorial a la que pertenece                         | Sí          |
| Image       | Imagen representativa                                | No          |
| Color       | Color hexadecimal identificatorio                    | No          |
| IsFeatured  | Indica si la franquicia es destacada                 | Sí          |
| IsOngoing   | Indica si la franquicia continúa vigente             | Sí          |
| IsActive    | Indica si la franquicia está activa en Comic Library | Sí          |

### Nombre

El nombre identifica a la franquicia dentro del catálogo.

No existe una restricción de unicidad global sobre el nombre.

Puede existir, por ejemplo:

```text
Marvel
└── Spider-Man

DC Comics
└── Spider-Man
```

La identificación de una franquicia se realiza mediante su `Id`.

---

## Relación con Editorial

Toda franquicia debe pertenecer obligatoriamente a una Editorial.

La relación es:

```text
Editorial
    │
    └── Franquicia
```

`PublisherId` es obligatorio.

Cuando la editorial de una franquicia sea desconocida, deberá utilizarse una editorial genérica denominada `Unknown`.

`Unknown` es una editorial real del catálogo y no un valor especial o `null`.

---

## Cambio de Editorial

El administrador podrá cambiar la Editorial asociada a una franquicia.

En el formulario de edición, la editorial actual se mostrará como información seleccionada y estará disponible una acción **Cambiar editorial**.

La acción llevará al administrador a una pantalla de selección de Editorial.

La pantalla de selección utilizará el listado de Editoriales existente, pero en modo selección:

* Permite buscar Editoriales.
* Permite utilizar los filtros disponibles.
* Permite ordenar.
* Permite paginar.
* Permite seleccionar una Editorial.
* No permite crear Editoriales.
* No permite editar Editoriales.
* No permite eliminar o desactivar Editoriales.

Una vez seleccionada una nueva Editorial, el administrador regresará al formulario de Franquicia con la nueva Editorial seleccionada.

El cambio de Editorial deberá requerir confirmación explícita antes de guardarse.

El cambio modifica únicamente la relación de la Franquicia con su Editorial.

No implica modificar directamente las relaciones futuras o existentes de Series o Novelas Gráficas asociadas a la Franquicia.

---

## Imagen

Una franquicia puede tener una única imagen representativa.

La imagen podrá utilizarse posteriormente como elemento visual en páginas o secciones dedicadas a la franquicia.

El administrador podrá:

* Cargar una imagen.
* Arrastrar y soltar una imagen.
* Seleccionar una imagen desde el sistema de archivos.
* Visualizar una previsualización.
* Reemplazar la imagen existente.
* Eliminar la imagen.

La imagen deberá almacenarse optimizada para utilización web.

No se requiere más de una imagen por franquicia.

---

## Color

Una franquicia podrá tener un color identificatorio.

El valor se almacenará como hexadecimal:

```text
#ED1C24
```

El administrador deberá poder seleccionar el color mediante un componente visual y, opcionalmente, introducir el valor hexadecimal.

El color es opcional.

Cuando una franquicia no tenga color configurado, las interfaces que utilicen la franquicia deberán utilizar el color predefinido correspondiente de la aplicación.

No se define en esta US el comportamiento visual concreto que tendrán las distintas interfaces públicas o administrativas al utilizar este color.

---

## Franquicia destacada

El administrador podrá marcar una franquicia como destacada mediante `IsFeatured`.

Esta información permitirá posteriormente realizar consultas de franquicias destacadas y utilizar la condición para determinar comportamientos visuales o de navegación.

El comportamiento visual concreto queda fuera del alcance de esta US.

---

## Franquicia vigente

`IsOngoing` indica si la franquicia continúa vigente y generando nuevas obras.

No representa si la franquicia está disponible o habilitada dentro de Comic Library.

Por lo tanto:

* `IsActive` indica si la franquicia está habilitada en Comic Library.
* `IsOngoing` indica si la franquicia continúa vigente/generando nuevas obras.

Una franquicia puede estar:

```text
IsActive = true
IsOngoing = true
```

o:

```text
IsActive = true
IsOngoing = false
```

Una franquicia también puede estar desactivada administrativamente independientemente de su estado de vigencia.

---

## Activación y desactivación

La franquicia no será eliminada físicamente del sistema.

El administrador podrá:

* Desactivar una franquicia.
* Reactivar una franquicia.

La desactivación modificará `IsActive` a `false`.

La activación modificará `IsActive` a `true`.

Ambas operaciones deberán solicitar confirmación explícita.

Una franquicia desactivada deberá continuar existiendo en el sistema para conservar sus relaciones y permitir su posterior reactivación.

El comportamiento concreto de cómo se muestran las franquicias desactivadas en las diferentes interfaces será definido en las especificaciones correspondientes.

---

# Listado de franquicias

El administrador dispondrá de una pantalla de listado de franquicias.

La pantalla deberá permitir:

### Búsqueda

La búsqueda podrá realizarse por:

* Nombre de la franquicia.
* Nombre de la Editorial.
* Nombre del País de la Editorial.

No se requiere búsqueda por otros campos.

### Filtros

Se podrán aplicar los siguientes filtros:

```text
Destacadas: [Todas | Sí | No]

Vigentes:   [Todas | Sí | No]

Activas:    [Todas | Sí | No]
```

### Ordenamiento

Se podrá ordenar por:

```text
Nombre
Nombre del País de la Editorial
Nombre de la Editorial
```

La dirección podrá ser:

```text
ASC
DESC
```

### Información mostrada

El listado deberá mostrar como mínimo:

```text
Imagen
Nombre
Editorial
Color
Destacada
Activa
Acciones
```

El estado booleano de las propiedades correspondientes deberá poder distinguirse visualmente.

El color se mostrará como una representación visual del color configurado, sin necesidad de mostrar el valor hexadecimal.

El listado deberá utilizar paginación.

---

# Alta de franquicia

Para crear una franquicia, el administrador deberá:

1. Ingresar al listado de franquicias.
2. Seleccionar la acción de crear franquicia.
3. Seleccionar una Editorial.
4. Completar el formulario de franquicia.
5. Confirmar la creación.
6. Guardar la franquicia.

La Editorial será obligatoria y deberá seleccionarse mediante la pantalla de selección de Editoriales.

La pantalla de selección no permitirá crear, modificar ni eliminar Editoriales.

---

# Edición de franquicia

Para editar una franquicia, el administrador deberá:

1. Seleccionar una franquicia desde el listado.
2. Acceder al formulario de edición.
3. Modificar sus datos.
4. Opcionalmente cambiar la Editorial mediante la acción **Cambiar editorial**.
5. Confirmar los cambios.
6. Guardar la franquicia.

La Editorial actual deberá estar claramente identificada en el formulario.

---

# Desactivación

Para desactivar una franquicia:

1. El administrador selecciona **Desactivar**.
2. El sistema muestra un mensaje de confirmación.
3. El administrador confirma.
4. El sistema establece `IsActive = false`.
5. El administrador regresa al listado actualizado.

La operación no elimina físicamente la franquicia.

---

# Reactivación

Para reactivar una franquicia:

1. El administrador selecciona **Reactivar**.
2. El sistema muestra un mensaje de confirmación.
3. El administrador confirma.
4. El sistema establece `IsActive = true`.
5. El administrador regresa al listado actualizado.

La operación no crea una nueva franquicia ni modifica sus relaciones.

---

# Relación con otras entidades

La relación conceptual del catálogo será:

```text
Editorial
    │
    └── Franquicia
          │
          ├── Serie
          │      └── Número
          │
          └── Novela Gráfica
```

Una Franquicia puede agrupar múltiples Series y, posteriormente, Novelas Gráficas.

La obligatoriedad de la relación:

```text
Serie → Franquicia
Novela Gráfica → Franquicia
```

será definida en las US correspondientes y no forma parte de la implementación de esta US.

---

# Reglas de negocio

1. Toda franquicia debe tener una Editorial.
2. `PublisherId` no puede ser `null`.
3. Si la Editorial real es desconocida, debe utilizarse la Editorial `Unknown`.
4. El nombre de la franquicia no necesita ser único.
5. Una misma denominación puede existir para franquicias pertenecientes a distintas Editoriales.
6. Una franquicia puede tener como máximo una imagen.
7. La imagen es opcional.
8. El color es opcional.
9. Cuando exista color, debe almacenarse como valor hexadecimal.
10. `IsFeatured` indica si la franquicia está marcada como destacada.
11. `IsOngoing` indica si la franquicia continúa vigente/generando nuevas obras.
12. `IsActive` indica si la franquicia está habilitada dentro de Comic Library.
13. `IsActive` e `IsOngoing` representan conceptos diferentes y deben mantenerse independientes.
14. Las franquicias no deben eliminarse físicamente.
15. Desactivar una franquicia debe conservar sus datos y relaciones.
16. Reactivar una franquicia debe recuperar la misma franquicia.
17. Cambiar la Editorial modifica la relación de la franquicia, no crea una nueva franquicia.
18. El cambio de Editorial requiere confirmación explícita.

---

# Pantallas

La gestión de franquicias requiere tres pantallas:

### 1. Listado de Franquicias

Permite:

* Buscar.
* Filtrar.
* Ordenar.
* Paginar.
* Crear.
* Editar.
* Desactivar.
* Reactivar.

### 2. Selección de Editorial

Utilizada durante el alta y para cambiar la Editorial durante la edición.

Debe basarse visual y funcionalmente en el listado de Editoriales existente, pero funcionar exclusivamente como selector.

### 3. Alta / Edición de Franquicia

Permite crear y modificar los datos de una franquicia.

La misma pantalla deberá soportar ambos modos.

---

# Fuera del alcance

Esta US no incluye:

* Gestión de Series.
* Gestión de Números.
* Gestión de Novelas Gráficas.
* Gestión de relaciones de continuidad.
* Gestión de listas.
* Gestión de Arcos.
* Gestión de Crossovers.
* Listas creadas por usuarios.
* Relaciones colaborativas.
* Recomendaciones.
* Funcionalidades de inteligencia artificial.
* Página pública de franquicia.
* Definición del diseño final de las páginas públicas que utilicen la imagen o el color de la franquicia.

Estas funcionalidades serán especificadas en US posteriores.

---

# Criterios de aceptación

### Listado

* El administrador puede consultar franquicias paginadas.
* Puede buscar por nombre de franquicia.
* Puede buscar por nombre de Editorial.
* Puede buscar por nombre de País de la Editorial.
* Puede filtrar por `IsFeatured`.
* Puede filtrar por `IsOngoing`.
* Puede filtrar por `IsActive`.
* Puede ordenar por nombre de franquicia.
* Puede ordenar por nombre del País de la Editorial.
* Puede ordenar por nombre de Editorial.
* Puede invertir la dirección del ordenamiento.

### Alta

* El administrador puede crear una franquicia.
* La Editorial es obligatoria.
* Puede seleccionar una Editorial desde el selector correspondiente.
* Puede informar descripción.
* Puede cargar una imagen.
* Puede reemplazar o eliminar la imagen antes de guardar.
* Puede definir un color.
* Puede marcar la franquicia como destacada.
* Puede indicar si está vigente.
* La nueva franquicia queda activa.

### Edición

* El administrador puede editar una franquicia existente.
* Puede modificar sus datos.
* Puede reemplazar o eliminar su imagen.
* Puede modificar su color.
* Puede modificar `IsFeatured`.
* Puede modificar `IsOngoing`.
* Puede cambiar la Editorial.
* El cambio de Editorial requiere confirmación.

### Activación y desactivación

* El administrador puede desactivar una franquicia.
* La desactivación requiere confirmación.
* La franquicia no se elimina físicamente.
* El administrador puede reactivar una franquicia.
* La reactivación requiere confirmación.
* La reactivación conserva los datos y relaciones existentes.

### Integridad

* Una franquicia nunca puede quedar sin Editorial.
* El nombre no requiere unicidad global.
* `IsActive` e `IsOngoing` son estados independientes.
* Una franquicia desactivada conserva su identidad y sus relaciones.
