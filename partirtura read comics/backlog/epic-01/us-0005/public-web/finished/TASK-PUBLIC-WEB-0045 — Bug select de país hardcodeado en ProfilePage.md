## Contexto

El usuario reportó que al editar el perfil, el select de países no es el mismo componente que se usa en el registro, y muestra países que no están en la base de datos.

## Problema

En `profile-page.tsx` (líneas 343-356), el select de nacionalidad está hardcodeado:

```tsx
<select>
  <option value="">Sin nacionalidad</option>
  <option value="1">Argentina</option>
  <option value="2">Uruguay</option>
  <option value="3">Chile</option>
  <option value="4">México</option>
  <option value="5">España</option>
  <option value="6">Colombia</option>
</select>
```

Esto causa:
1. No reutiliza el componente `CountrySearchSelect` que ya existe en `features/authentication/components/country-search-select.tsx` y que usa el endpoint `/api/countries`.
2. Muestra países hardcodeados que pueden no coincidir con la base de datos real.
3. Si se agrega/modifica un país en el backend, el perfil no se actualiza.

## Solución propuesta

Reemplazar el `<select>` hardcodeado por el componente `CountrySearchSelect` existente, igual que se usa en el formulario de registro.
