Controllers covered:
- PublishersController — Public catalog filters
- AdminPublishersController — Dashboard administration

Related:

## GET /api/publishers/{id}

Description:
Returns the detail of one publisher for the Public Web publisher page (`/publishers/:id`). Provides everything needed to render the publisher header: name, entity color, logo, country, founded year, website, short description and history.

Controller:
PublishersController

Audience: Public Web authenticated users.

Authentication:
- Required. Bearer token in Authorization header.
- Any authenticated user. Does not require the Administrator role.
- Anonymous access is not allowed.
- Not part of any anonymous-access controller group.

Request parameters:
- id: long (required, publisher id in the path)

Response:
- 200 OK
  Body:
  {
      "success": true,
      "message": "OK",
      "code": 200,
      "payload": {
          "id": 2,
          "name": "Zenescope",
          "color": "#0b3d91",
          "urlImage": "/images/100",
          "countryName": "United States",
          "foundedYear": 1999,
          "website": "https://www.zenescope.com",
          "description": "American comic book publisher.",
          "history": "Founded in Los Angeles in 1999..."
      }
  }
- 404 Not Found when the publisher does not exist or is deactivated (`IsActive = false`). Both cases return the same message, so the endpoint does not reveal whether a deactivated id exists.
- 401 Unauthorized when the bearer token is missing or invalid.

DTO:
`Application/DTOs/PublisherDetailDto.cs` — `PublisherDetailDto`.

Behavior and contract notes:
- Optional data may be absent: `color`, `urlImage`, `countryName`, `foundedYear`, `website`, `description` and `history` are `null` when the publisher has no value. Missing optional data never throws and no placeholder values are generated by the backend.
- The publisher image is the publisher **logo**. It is returned as a URL built with the project image mechanism (`/images/{imageId}`), not as a storage path. The image is served through the existing images endpoint with its current access rules.
- Field names follow the domain, not the Draft sketch: `foundedYear` (domain `Publisher.FoundedYear`) and `description` (domain `Publisher.Description`), and the image URL is exposed as `urlImage`, the name already used by the rest of the API. `foundationYear`, `shortDescription` and `imageUrl` are **not** part of the response.
- Administrative data is never exposed: no `isActive`, `isFeatured`, `isAlive`, `createdAt`, `countryId`, `imageId` or storage information.
- No publisher hierarchy (Franchises or Series) is included. Franchise and Series data is available through `GET /api/franchises?publisherId={id}` and `GET /api/series?publisherId={id}`.
- `id` is part of the technical contract (needed to locate the resource) even though it is not displayed in the UI.

## GET /api/publishers

Description:
Returns a paginated list of active publishers for the public catalog filters (autocomplete of `GET /api/works`). Never returns inactive publishers.

Controller:
PublishersController

Authentication:
- Required. Bearer token in Authorization header.
- Does not require the Administrator role.

Request parameters:
- currentPage: integer (default 1)
- pageSize: integer (default 12, max 24)
- orderBy: string (optional, allowed: Name, Country)
- orderDir: string (default ASC)
- search: string (optional, partial case-insensitive match on publisher name or country name)

Response:
- 200 OK
  Body:
  {
      "success": true,
      "message": "OK",
      "code": 200,
      "payload": {
          "currentPage": 1,
          "hasNextPage": true,
          "hasPriorPage": false,
          "totalPages": 3,
          "pageSize": 12,
          "nextPage": 2,
          "priorPage": null,
          "totalCount": 30,
          "items": [
              {
                  "id": 2,
                  "name": "Marvel Comics",
                  "color": "#EC1D24"
              }
          ]
      }
  }
- 401 Unauthorized when the bearer token is missing or invalid.

DTO:
`Application/DTOs/CatalogFilterDtos.cs` — `PublisherFilterDto` (Id, Name, Color).

## POST /api/admin-publishers

Description:
Creates a new publisher, including optional avatar management.

Controller:
AdminPublishersController

Authentication:
- Required. Bearer token in Authorization header.
- Requires Administrator role.

Request:
- Content-Type: multipart/form-data
- Body:
  - name: string
  - description: string (optional)
  - website: string (optional)
  - countryId: long
  - foundedYear: int (optional)
  - history: string (optional)
  - isAlive: boolean
  - avatar: IFormFile (optional, binary image file)
  - color: string (optional)
  - isFeatured: boolean

Response:
- 200 OK
  Body:
  {
      "success": true,
      "message": "Publisher created successfully.",
      "code": 200,
      "payload": {
          "id": 1
      }
  }

Response Type:
ApiResponse<object>

Errors:
- 400 Bad Request
  {
      "success": false,
      "message": "El nombre es obligatorio.",
      "code": 400,
      "payload": { "detail": "El nombre es obligatorio." }
  }
- 404 Not Found
  {
      "success": false,
      "message": "El país no existe o no está activo.",
      "code": 404,
      "payload": null
  }
- 409 Conflict
  {
      "success": false,
      "message": "Ya existe una editorial con el mismo nombre.",
      "code": 409,
      "payload": null
  }

Notes:
- Requires authentication.
- Requires Administrator role.
- Name is mandatory and must be unique.
- Country is mandatory and must be active.
- Avatar is optional; when provided, it is stored as a new image and linked to the publisher.
- Color is optional; when provided, it must be a valid hexadecimal value in format #RRGGBB.
- The new publisher is created with IsActive = true.
- IsActive cannot be set through this endpoint.
- Avatar management is integrated into this endpoint using multipart/form-data.
- No existen endpoints independientes de imagen para este flujo.

## PUT /api/admin-publishers/{publisherId}

Description:
Updates an existing publisher, including optional avatar management.

Controller:
AdminPublishersController

Authentication:
- Required. Bearer token in Authorization header.
- Requires Administrator role.

Request:
- Content-Type: multipart/form-data
- Body:
  - name: string
  - description: string (optional)
  - website: string (optional)
  - countryId: long
  - foundedYear: int (optional)
  - history: string (optional)
  - isAlive: boolean
  - imageId: long (optional)
  - avatar: IFormFile (optional, binary image file)
  - color: string (optional)
  - isFeatured: boolean

Response:
- 200 OK
  Body:
  {
      "success": true,
      "message": "Publisher updated successfully.",
      "code": 200,
      "payload": {
          "id": 1
      }
  }

Response Type:
ApiResponse<object>

Errors:
- 400 Bad Request
  {
      "success": false,
      "message": "El nombre es obligatorio.",
      "code": 400,
      "payload": { "detail": "El nombre es obligatorio." }
  }
- 404 Not Found
  {
      "success": false,
      "message": "La editorial no existe.",
      "code": 404,
      "payload": null
  }
- 409 Conflict
  {
      "success": false,
      "message": "Ya existe una editorial con el mismo nombre.",
      "code": 409,
      "payload": null
  }

Notes:
- Requires authentication.
- Requires Administrator role.
- The publisher identifier comes from the route.
- Name must be unique across other publishers.
- Country is mandatory and must be active.
- Avatar management is integrated into this endpoint using multipart/form-data.
- imageId = existingId + avatar = null → conservar imagen actual.
- imageId = 0 + avatar = archivo → reemplazar imagen actual.
- imageId = 0 + avatar = null → eliminar imagen actual.
- Color is optional; when provided, it must be a valid hexadecimal value in format #RRGGBB.
- IsActive cannot be modified through this endpoint.
- No existen endpoints independientes de imagen para este flujo.

ApiResponse<object>

      "success": false,

  }
